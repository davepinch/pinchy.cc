excerpt: >-
  The **Xerox Alto** is a computer system developed at Xerox PARC (Palo Alto Research Center) in the 1970s. It is considered one of the first workstations or personal computers, and its development pioneered many aspects of modern computing. The advances include graphical user interface (GUI), computer mouse, Ethernet networking, and the ability to run multiple applications simultaneously. It is one of the first computers to use a WYSIWYG (What You See Is What You Get) text editor and has a bit-mapped display. The Alto did not succeed commercially, but it had a significant influence on the development of future computer systems.
